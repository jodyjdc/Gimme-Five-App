# Gimme Five

Web app interattiva per creare cinque classifiche Top 5 in tempo reale.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the app:

   ```bash
   npm run dev
   ```
